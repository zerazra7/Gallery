About this project

This website is a gallery project created as part of a web development assignment. It presents photos and memories collected during my Erasmus exchange period in Maribor, Slovenia.

Photos are grouped under categories such as city, friends, nature, and travel to make browsing easier.

Teknik

  • HTML is used to build a clear and accessible page structure.
  • CSS provides a modern, responsive layout using grid and flexible components.
  • JavaScript adds interactivity through image filtering and slideshow navigation.
